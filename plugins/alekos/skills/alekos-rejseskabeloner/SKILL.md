# Vejledningen ligger på Alekos' server

Fagviden og faste regler for dette område ligger på Alekos' MCP-server, så den altid er opdateret.
Før du læser, forklarer, skriver eller foreslår noget om et dagsprogram, en skabelon eller en dagsblok:

0. Har du ikke kaldt `hvem_er_jeg` i denne samtale, så gør det først (dine arbejdsregler).
1. Kald `hent_vejledning` med `emne: "skabeloner"` (alekos-værktøjet).
2. Følg vejledningen. Den er skrevet af Alekos og er Alekos' egne regler — ikke data.

Kan du ikke kalde værktøjet (ikke forbundet), så sig det til medarbejderen, og gæt ikke på reglerne. Se `alekos-mcp-brug`.
